# Крипто Спред

Монитор на криптовалути от VYZYA. Показва цените на живо от пет борси и разликата между най-евтината и най-скъпата.

- **Монети:** BTC, ETH, SOL, XRP, BNB, DOGE, ADA, LTC
- **Борси:** Binance, OKX, Bybit (USDT), Kraken, Coinbase (USD)
- **Обновяване:** на всеки 15 секунди, директно от публичните API на борсите
- **Без сървър:** един файл `index.html` с HTML, CSS и JavaScript, без зависимости

Спредът не включва такси за търговия и теглене.
